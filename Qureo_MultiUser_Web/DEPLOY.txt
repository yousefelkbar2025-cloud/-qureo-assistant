تشغيل وتجهيز الموقع أونلاين
============================
هذه حزمة تطبيق متعددة المستخدمين (كل مستخدم له حساب مستقل) وتعمل على الكمبيوتر والتابلت من خلال رابط واحد بعد النشر.

للتجربة محليًا على Windows:
1) ثبّت Python 3.10 أو أحدث.
2) افتح مجلد المشروع في Terminal/CMD.
3) نفّذ:
   python -m venv .venv
   .venv\Scripts\activate
   pip install -r requirements.txt
   set SECRET_KEY=اكتب-قيمة-عشوائية-طويلة-هنا
   python app.py
4) افتح http://127.0.0.1:5000

للنشر:
- ارفع محتويات المجلد إلى خدمة استضافة تدعم Python/Flask.
- اجعل أمر التشغيل: gunicorn app:app
- أضف متغير البيئة SECRET_KEY بقيمة عشوائية طويلة وسرية.
- استخدم HTTPS، وقرصًا دائمًا/تخزينًا دائمًا لقاعدة البيانات وملف answers.txt.
- لا ترفع qureo_users.db إلى مستودع عام.
- الحسابات تحفظ كلمات مرورها كـ hashes، وليس كنص صريح.

مهم:
- ملف answers.txt هو قاعدة الإجابات المشتركة المستخرجة من ملف المستخدم.
- هذه النسخة لا تجمع بيانات دخول QUREO ولا تدخل للمنصة ولا تسلّم واجبات نيابة عن المستخدم.
- البحث تقريبي؛ راجع كل نتيجة قبل استخدامها.
- يلزم ضبط الاستضافة الفعلية وربط نطاق/رابط قبل أن يصبح الموقع عامًا.
